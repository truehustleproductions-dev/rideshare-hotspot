# Rideshare Hotspot PWA

Personal mobile-first rideshare companion. This repository is designed for GitHub Pages.

## V1 runtime
- HTTPS/PWA shell and offline cache
- Canonical local Trip Record storage
- Voice capture with explicit microphone permission handling
- Screenshot evidence/manual capture
- Trip lifecycle, Black Box, earnings reconciliation, work-zone controls, Get Me Home, hotspot intelligence, analytics and local Copilot
- Uber/Lyft APIs remain intentionally disconnected until genuine API access exists
- OpenAI-backed vision/Copilot requires a secure server-side provider and is not embedded in this static client
